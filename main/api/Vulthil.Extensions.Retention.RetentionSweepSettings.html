Class RetentionSweepSettings

Namespace
Vulthil.Extensions.Retention
Assembly
Vulthil.Extensions.Retention.dll

How a retention sweep runs: a sweep starts on host start and then every SweepInterval, deletes entries older than RetentionPeriod, and does so in batches of BatchSize until fewer than a full batch remain. Callers validate these values on their own options before registering the sweep.
