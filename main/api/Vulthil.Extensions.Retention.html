RetentionSweepServiceCollectionExtensions

Service-collection extension that registers a retention sweep for a store.

RetentionSweepSettings

How a retention sweep runs: a sweep starts on host start and then every SweepInterval, deletes entries older than RetentionPeriod, and does so in batches of BatchSize until fewer than a full batch remain. Callers validate these values on their own options before registering the sweep.

Delegates

RetentionSweepDeleter

Deletes up to batchSize entries that became eligible for retention before olderThanUtc and returns how many were deleted. A store exposes its own delete operation in this shape so the sweep registered by AddRetentionSweep<TStore>(IServiceCollection, string, Func<IServiceProvider, RetentionSweepSettings>, Func<TStore, RetentionSweepDeleter?>) can drive it without knowing the store's type.
