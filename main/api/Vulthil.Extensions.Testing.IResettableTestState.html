State that a test double keeps in a test host's services — captured messages, registered stubs, an in-memory store — and that is reset to a clean baseline after each test, so tests that share one host never see each other's state.

Remarks

Register the implementation in the test host's services as an IResettableTestState, usually as a forward to the singleton that holds the state: 

services.AddSingleton<InMemoryEmailSender>();
services.AddSingleton<IEmailSender>(sp => sp.GetRequiredService<InMemoryEmailSender>());
services.AddSingleton<IResettableTestState>(sp => sp.GetRequiredService<InMemoryEmailSender>());

A test framework adapter resets every registered instance after each test. Vulthil.xUnit resets the instances of every live test host while the hosts' restartable background services are paused, and cancels the token when a reset takes too long. With no such adapter, resolve the instances from the host's services in the per-test teardown and call ResetAsync(CancellationToken) on each.

The reset runs after each test, not before it: what the host records while it starts, or while its background services restart after a reset, is visible to the next test.
