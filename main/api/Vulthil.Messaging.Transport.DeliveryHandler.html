One registered consumer or request consumer, as a DeliveryDispatcher runs it for a delivered message. DeliveryHandlerFactory builds one per registration; a transport keeps them in a MessageExecutionRegistry<THandler> and hands a plan's handlers to the dispatcher.

Identity

Gets the handler's stable identity: the consumer's CLR full name and the registered message type's full name, joined by a colon. A transport that redelivers later carries these identities on the redelivery so only the handlers that failed run again (see RedeliveryHandlerIdentities).
