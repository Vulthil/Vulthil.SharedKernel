Class DeliveryHandlerFactory

Namespace
Vulthil.Messaging.Transport
Assembly
Vulthil.Messaging.dll

Builds the DeliveryHandler for each consumer registration, so a transport's MessageExecutionRegistry<THandler> holds handlers a DeliveryDispatcher can run. Each attempt resolves the consumer from the attempt's scope, builds the receive context through the IDeliveryPort, and runs the consume pipeline; a request consumer's attempt then sends its RpcReply through the port.

CreateRequestConsumerHandler<TConsumer, TRequest, TResponse>(RetryPolicyDefinition?)

Builds the handler for a request/reply IRequestConsumer<TRequest, TResponse> registration. Called once per registration while MessageExecutionRegistry<THandler> assembles execution plans.

Parameters

Remarks

The handler ignores retryPolicy: a request consumer never retries, and replies with an RpcFault instead.
