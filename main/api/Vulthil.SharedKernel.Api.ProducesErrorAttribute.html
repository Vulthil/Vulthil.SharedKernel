Declares that an endpoint or controller action can fail with the given ErrorType, so OpenAPI documents the matching problem response. The status code and body schema come from the same mapping the result extensions use at runtime (CustomResults), so endpoint code names the errors it can produce and never a status code. Apply one attribute per error type; a 500 response is documented on every operation without a declaration, because an unclassified failure is always possible.

Remarks

This is a ProducesResponseTypeAttribute, so both the minimal API metadata pipeline and the MVC API explorer pick it up without further wiring: apply it to a controller action, a controller class, or a minimal API handler lambda, or use ProducesErrors<TBuilder>(TBuilder, params ErrorType[]) on a route builder.
